## SmartParkingSensor

## componants
Arduino UNO r3
HC-SR04 Ultrasonic sensor x2
LSM9DS1 IMU 
16x2 LCD display
74HC595 shift register (for LCD)
Green LED x2
Yellow LED x2
Red LED x2
Buzzer x1
Push button x1
Resistors 220Ohm(for LEDs)
